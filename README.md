# Enhanced Tools Mod

Boost your Minecraft experience with powerful tools and items

## Features

- Veinminer tool for mining connected blocks
- Golden Hunger item for custom resource restoration
- Upgradeable Backpack for increased storage
- Upgradeable Furnace for faster smelting
- Custom Food items with unique properties

## Requirements

- Minecraft 1.20.1
- Forge 47.1.0

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/enhanced-tools-mod/releases)
2. Place the mod file in your Minecraft mods folder
3. Launch Minecraft with Forge

## Usage

- **Veinminer**: Right-click to activate, then crouch to mine connected blocks
- **Golden Hunger**: Right-click to restore custom resources
- **Upgradeable Backpack**: Right-click to open and upgrade
- **Upgradeable Furnace**: Right-click to open and upgrade
- **Custom Food**: Eat to gain unique effects

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
